# Code of Conduct

Bilinc contributors are expected to be respectful, specific, and constructive.

We welcome good-faith questions, disagreement about architecture, reproducible criticism, and beginner contributions.
Harassment, discrimination, personal attacks, doxxing, credential sharing, and deliberate benchmark manipulation are not
acceptable.

Maintainers may remove comments, close discussions, or reject contributions that violate this standard. Please report
concerns privately through the repository's security or maintainer contact path rather than publishing sensitive details.
