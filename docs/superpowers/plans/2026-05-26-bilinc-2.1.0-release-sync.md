4. **Hermes/local verification imports local checkout instead of PyPI package.**
   - Mitigation: `env -u PYTHONPATH`, temp venv install, print module path/version.

5. **Badges return HTTP 200 but stale/rate-limited text.**
   - Mitigation: parse SVG content, not only status.

6. **Live site deploy uses stale cache/build.**
   - Mitigation: clear cache before fresh deploy; verify external domain after restart.

1. `pyproject.toml` still says `1.2.5` while PyPI latest is `2.0.0`; this release must fix version discipline.
2. Local bilinc-site path is not a git repo, so source-of-truth/deploy path must be identified before website deployment.
3. ReARCLabs/Bilinc divergence is not a release chore; it is a release-line decision.

### Paper Tigers

1. GitHub Actions checkout 403 from earlier PR #11 was auth/infrastructure; PR #12 later proved CI can run green with correct token/path.

## Abort Conditions

Abort and report before public publish/deploy if:
- `2.1.0` already exists on PyPI.
- build/twine check fails.
- clean install cannot import new public modules.
- secret scan finds a real token.
- website deployment target/rollback path cannot be verified.
- ReARCLabs sync would require force-push.
